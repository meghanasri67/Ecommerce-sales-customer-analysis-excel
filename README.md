# E-Commerce Sales & Customer Analysis using Excel

## 📌 Project Overview

This project focuses on analyzing an E-Commerce Sales and Customer dataset using Microsoft Excel.

The main objective of this project is to clean the data, perform Exploratory Data Analysis (EDA), identify sales and customer patterns, and generate meaningful business insights using Excel.

---

## 🎯 Objectives

- Clean and prepare the e-commerce dataset
- Perform Exploratory Data Analysis (EDA)
- Analyze sales performance over time
- Analyze different sales channels
- Analyze regional performance
- Analyze payment methods
- Analyze customer segments
- Identify important business insights
- Create Pivot Tables and visualizations for better understanding

---

## 🛠️ Tools Used

- Microsoft Excel
- Excel Tables
- Pivot Tables
- Excel Charts
- Data Cleaning
- Exploratory Data Analysis (EDA)

---

## 🧹 Data Cleaning & Quality Checks

The dataset was checked and prepared before performing the analysis.

The following checks were performed:

- Checked for duplicate records
- Checked for missing values
- Checked data types
- Verified Order IDs
- Checked date ranges
- Organized the cleaned dataset for analysis

### Data Quality Summary

- Total Records: **289**
- Total Columns: **41**
- Duplicate Rows: **0**
- Rows with Missing Values: **0**
- Unique Order IDs: **289**
- Date Range: **2021–2025**

---

## 📊 Analysis Performed

### 1. Yearly Sales Analysis

Year-wise net sales were analyzed to understand sales trends over time.

The analysis shows that **2025 recorded the highest net sales** in the dataset.

### 2. Sales Channel Analysis

Sales performance was analyzed across different channels:

- Marketplace
- Mobile App
- Social Media
- Website

The **Mobile App recorded the highest net sales** among the channels in this dataset.

### 3. Regional Analysis

Regional performance was analyzed across:

- Central
- East
- North
- South
- West

The **South region recorded the highest profit** in the analyzed data.

### 4. Payment Method Analysis

Different payment methods were analyzed to understand their contribution to net sales.

Payment methods include:

- Bank Transfer
- Buy Now Pay Later
- Cash on Delivery
- Credit Card
- Debit Card
- Digital Wallet
- PayPal

**Credit Card recorded the highest net sales** among the payment methods in this dataset.

### 5. Customer Segment Analysis

Customer segments were analyzed based on sales, orders, profit, and average profit margin.

The segments include:

- Business
- Consumer
- Premium
- VIP

The **Consumer segment generated the highest net sales and profit** in the dataset.

---

## 🔍 Key Insights

- **2025 generated the highest yearly net sales.**
- **Mobile App was the largest sales channel by net sales.**
- **South region contributed the highest profit.**
- **Consumer customers generated the largest share of net sales.**
- **Credit Card recorded the highest net sales among payment methods.**
- All 289 orders are marked as **Refunded, Cancelled, or Returned**, while positive net sales and profit are recorded. This indicates a potential inconsistency between the Order Status and financial fields that should be validated.
